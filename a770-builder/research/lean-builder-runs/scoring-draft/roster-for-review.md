# Proposed scored task definitions

This revision incorporates the independent review of the task definitions. The exact Lean propositions, baseline commits, public examples, and hidden graders still require validation and sign-off before freezing. Each task would have one editable implementation module and separate common public examples and reviewer-only hidden cases. The behavioral contract and the Lean proposition must state the same requirements. Validate each compiled proposition and grader against good and deliberately faulty controls before freezing hashes.

| Task | Proposed observable contract | Public example and hidden discriminators |
| --- | --- | --- |
| Longest affordable prefix | Natural budget and ordered natural costs. Return the longest initial segment whose sum fits. Preserve zeros, including after the budget reaches zero. | Public: budget 5 and costs [2,4,1] select [2]. Hidden: zero-cost suffix after exact exhaustion, leading unaffordable item, and large naturals. |
| Log-count aggregation | Given a list of normalized rows with severity of type `String` and count of type `Nat`, and a list of requested severity strings, return natural-number totals in request order. Use exact, case-sensitive string equality, with no normalization at this step. An absent severity totals zero. Repeated requests repeat the same total. | Public: rows [('warn',2),('warn',3)] and requests ['warn','info'] yield [5,0]. Hidden: interleaved severities, zero rows, empty requests and repeated requests. |
| Minute selection with ties | Given a `List (Nat × Nat)` of (minute, score) observations, return the minute of the first observation in list order attaining the highest score. The result type is `Option Nat`. Empty input returns `none` and nonempty input returns `some minute`. Minutes need not be sorted. | Public: [(12,4),(8,5),(7,5)] selects 8. Hidden: all scores equal, repeated minutes, later unique maximum and empty input. |
| Interval coalescing | Represent an interval as `Nat × Nat` in (start, end) order. Discard input intervals with end ≤ start. Each remaining interval covers exactly the naturals `n` with start ≤ `n` < end. Return nonempty half-open intervals sorted by strictly increasing start. For every natural `n`, membership in the union of the outputs is equivalent to membership in the union of the valid inputs. Consecutive outputs satisfy previous end < next start, so overlapping and touching intervals coalesce. | Public: [(4,6),(1,4),(3,5)] yields [(1,6)]. Hidden: nested intervals, gaps of one, duplicates, and invalid intervals. |
| Stable deduplication | Return each natural that appears in the input once, in first-occurrence order. | Public: [2,1,2,3,1] yields [2,1,3]. Hidden: already unique, all equal, empty, and nonadjacent repeats. |
| Sorted merge with multiplicities | Merge two nondecreasing lists of naturals. Return a nondecreasing list with exactly the sum of the inputs’ occurrence counts for every value. Inputs outside the sorted precondition need no behavior. | Public: [1,2,2] merged with [2,3] yields [1,2,2,2,3]. Hidden: both empty, one empty, repeated head values, and exhaustion of either input. |
| Bounded state transition | Given capacity and balance of type `Nat` and events of type `List (Sum Nat Nat)`, where `Sum.inl amount` is a deposit and `Sum.inr amount` is a withdrawal, clamp the initial balance to capacity. Apply each event in order. A deposit is capped at capacity and a withdrawal floors at zero. Return the final balance. | Public: capacity 5, balance 3, events +4 then −2 yield 3. Hidden: state starting above capacity, zero capacity, underflow before a deposit, reversed events. |
| Field projection | Given ordered rows with identifier and minute of type `Nat` and enabled of type `Bool`, return the identifiers in input order. Keep every row and preserve duplicates. | Public: rows [(4,90,false),(4,12,true),(1,0,false)] yield [4,4,1]. Hidden: empty input and rows with conflicting flags. |

For minute selection, first-observation tie-breaking makes the output depend on input order. Choosing the numerically earliest minute would exercise a different contract. For interval coalescing, requiring strict output separation makes the representation canonical and can be checked separately from coverage. These choices should appear in the prose and formal task packets.

Field projection is provisionally retained as the brief’s low-benefit control. Its simplicity gives it limited power to discriminate between arms and makes a ceiling effect plausible. Filtering for enabled rows would add a behavioral rule and make the comparison less routine. Keep the projection’s per-task outcomes visible when reporting the aggregate and its leave-one-task-out sensitivity.
